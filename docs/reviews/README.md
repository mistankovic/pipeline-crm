# Stage reviews

Each stage produces:

1. A Builder hand-off (`stage-NN-builder-handoff.md`)
2. An Adversarial Reviewer report (`stage-NN-review.md`)
3. Fix notes if the reviewer rejected the stage (`stage-NN-fixes.md`, numbered)

The Builder must not start stage N+1 until the reviewer report contains the
line `STAGE N APPROVED`.
