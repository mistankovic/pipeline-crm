## What this run found

The first attempt reported **34 of 34 failing**. None of that was the application: Playwright
could not launch a browser, because the pinned build is not downloadable in this environment
and `PLAYWRIGHT_CHROMIUM_PATH` — which every earlier run had set from the shell — was
documented nowhere. A reader following `docs/qa/procedures.md` exactly would have hit the same
wall and had no way to know what to do about it.

Fixed by documenting the variable in the procedures document, with an explicit warning that a
launch failure is not a QA result. The run above is after that fix.

This is worth recording rather than quietly correcting: the QA suite's own setup was the least
tested part of it, and it took running from a genuinely cold shell to notice.
